# Checks da Task 2

O mesmo critério machine-checkable da correção. Crédito parcial: cada critério zera só o próprio peso.

A partir da raiz deste pacote:

```bash
python checks/check_task2.py --submission /caminho/do/repo/do/grupo
```

`--dados` é opcional: o default é a pasta `dados/` ao lado de `checks/`.

Pesos: ver [`../enunciado.md`](../enunciado.md).
